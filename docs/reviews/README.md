# Reviews

Adversarial read-only reviews are run after each implementation phase; findings are fixed in a follow-up round.

- `open-findings.md`: findings not yet fixed, design items, known limits and test gaps. The next fix round works
  from this file. A round's status notes live there while it runs; once the lead accepts the round they are
  removed, what it left open is kept, and the round gets a row below naming the commit that still has its notes.
- `integration-notes.md`: API changes other layers must adopt, collected from the fix agents, with what each round
  leaves to check by hand in the app.
- `2026-10-01-general-code-review.md`: the latest full review, kept; its "Status at a glance" says which groups are
  done (with their commits) and which are open.
- `2026-10-01-grading-pipeline-decision.md`: the approved decision on where colour grading sits in the pipeline.
